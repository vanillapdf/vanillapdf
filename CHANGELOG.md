# Changelog

Release notes for Vanilla.PDF are published on the
[GitHub Releases page](https://github.com/vanillapdf/vanillapdf/releases),
generated and curated per tag as part of the release process (see
`RELEASE-GUIDE.md`). That page is the authoritative changelog — this file
exists only so tooling and contributors that expect a `CHANGELOG.md` have
somewhere to look.

- **Latest release**: https://github.com/vanillapdf/vanillapdf/releases/latest
- **All releases**: https://github.com/vanillapdf/vanillapdf/releases
- **Compare any two versions**: `https://github.com/vanillapdf/vanillapdf/compare/vX.Y.Z...vA.B.C`
