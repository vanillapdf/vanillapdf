# Self-Improvement

After any of these events, immediately update the appropriate `.claude/rules/lessons/` file:

- A build or CI failure caused by a pattern that could recur
- A mistake that required correction or multiple attempts
- A merge conflict with a non-obvious resolution
- A new project convention or workflow was established

Keep entries to one line each. Check existing entries first to avoid duplicates. Stage lesson files with the current work — do not create a separate branch just for lessons.

For detailed procedure, see `/session-retrospective`.
