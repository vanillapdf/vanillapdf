# Test fixtures

The minimal set of test assets kept **in this repository**, as opposed to the
mass test corpus, which lives in the external
[vanillapdf-testdata](https://github.com/vanillapdf/vanillapdf-testdata) release
and is fetched on demand.

Everything here is **authored or generated by this project** — there are no
third-party documents, no embedded third-party fonts, no sourced images, and no
personal information. That keeps the public repository free of redistribution or
licensing questions. Do not add real-world PDFs here; put those in the external
corpus with per-file provenance instead.

## Contents

| File | Origin | How to regenerate |
|------|--------|-------------------|
| `minimalist.pdf` | vanillapdf-authored, a tiny valid PDF (catalog + empty page tree) | hand-authored |
| `flat-pages.pdf` | 1,450 empty pages in a flat `/Pages` tree, for the page-tree benchmark | `vanillapdf.tools generate -d fixtures/flat-pages.pdf -p 1450` |
| `sample-document.pdf` | A feature-rich document: standard PDF fonts (not embedded), a procedurally drawn image, an underline, internal + external links, and a table | `python scripts/generate_sample_documents.py` |
| `certificates/*.pfx` | Internal test signing certificates (DSA/RSA/EC/Ed25519/Ed448). Not real credentials — no trust path, password `test` | generated test fixtures |

## Consumers

- `vanillapdf.benchmark` — `flat-pages.pdf` (page tree), `sample-document.pdf`
  (content stream), and all three PDFs for the IO-strategy size range.
- `vanillapdf.unittest` — `certificates/*.pfx`, compiled into a header.
- `signature-interop-check` workflow — signs a fixture with `certificates/*.pfx`.

## Notes

- `sample-document.pdf` is emitted with Flate (not ASCII85) streams so vanillapdf
  can round-trip it — see the note in `scripts/generate_sample_documents.py`.
- `flat-pages.pdf` tags each page with a unique key as a workaround for
  [#458](https://github.com/vanillapdf/vanillapdf/issues/458) (the writer
  deduplicates content-identical objects). Drop that key once #458 is fixed.
